# 발음 지도 참고자료 요약

출처: 2026년 4~5월 연수자료 (정종성, 청주교육대학교) — 경계선지능/기초학력 학생을 위한 읽기 지도. 세부 내용을 전부 기억할 필요는 없고, **아래 흐름과 지도 방법의 큰 줄기**만 참고해서 발음 지도 앱 설계에 반영한다.

## 교재의 전체 구성 흐름

1. 읽기란 무엇인가 (해독·유창성·독해, 지도 모형)
2. 한글 단어를 읽는 능력이 어떻게 발달하는가 (발달 단계)
3. 학생의 현재 수준을 어떻게 파악하는가 (초기 문해력 검사 영역)
4. 글자/소리를 어떤 원칙으로 지도하는가 (자소·음소 지도 원칙)
5. 연습 자료(텍스트·단어)의 난이도를 어떻게 조절하는가
6. 실제 지도 회기를 어떤 순서로 구성하는가

## 핵심 지도 방법

- **발달 단계를 따라간다**: 통단어 읽기 → 글자 읽기 → 자소 읽기 → 자동화된 읽기. 우리가 정한 "자모 → 음절 → 단어" 진행 순서가 이 발달 단계와 일치한다.
- **소리를 지도하는 순서**: 초성 → 종성(받침), 받침 없는 글자(민글자) → 받침 있는 글자.
- **맥락 속에서 명시적으로 지도**한다 (책/문장 → 낱말 → 자소 순으로 좁혀가며).
- 헷갈리기 쉬운 자소는 뒤로 미루고, 학생에게 의미 있는 낱말부터 다룬다.
- 연습 자료(단어)의 난이도는 **받침 유무·위치**와 **음운변동 유무**(연음, 비음화, 구개음화, ㅎ탈락 등 발음이 표기와 달라지는 경우)로 조절한다.
- 지도 회기는 보통 "익숙한 것 반복 → 새 낱말/소리 익히기 → 짧게 활용해보기 → 새로운 자료 소개" 순서로 구성하고, 시작 전 학생과의 라포 형성과 현재 수준 파악이 먼저다.

## 발음 지도 앱 설계에 적용할 점

- 단계 구성(자모→음절→단어→문장)은 위 발달 단계 순서와 같은 방향이므로 그대로 유지한다.
- 단어 목록을 만들 때 "받침 없음 → 받침 있음(쉬운 것 → 음운변동 있는 것)" 순으로 난이도를 올린다.
- 한 회기(또는 한 세션)의 연습량은 짧고 반복적으로 구성하는 것이 좋다 (학생이 이미 아는 것 위주로 시작해 점차 새 것을 섞는 방식).
- 오류를 볼 때 "발음이 표기와 원래 다르게 나는 경우(음운변동)"인지, 실제 오조음인지 구분할 수 있으면 더 정확한 피드백을 줄 수 있다 (추후 고도화 아이디어로 남겨둔다).
