# LLM 활용 위키

우리 팀/프로젝트에서 LLM(대형 언어 모델)을 어떻게 활용할지 정리한 내부 위키입니다.
Claude(Anthropic) API를 기준으로 작성되었으며, 필요에 따라 다른 제공자 내용도 추가할 수 있습니다.

## 목차

0. [프로젝트 에이전트 가이드](00-프로젝트-에이전트-가이드.md) — 새 교육용 앱 프로젝트를 시작할 때마다 그 프로젝트 폴더에 복사해서 에이전트에게 보여주는 100줄 이내 요약본
1. [모델 선택 가이드](01-모델-선택-가이드.md) — 어떤 모델을 언제 쓸지
2. [프롬프트 작성 가이드](02-프롬프트-작성-가이드.md) — 좋은 프롬프트를 쓰는 기본 원칙
3. [API 사용법](03-API-사용법.md) — 인증, 기본 요청, 스트리밍
4. [비용 관리](04-비용-관리.md) — 캐싱, effort 조절, 배치 처리로 비용 절감
5. [보안 및 데이터 프라이버시](05-보안-및-데이터-프라이버시.md) — 민감 정보 취급 원칙
6. [FAQ](06-FAQ.md) — 자주 묻는 질문
7. [발음 지도 참고자료 요약](07-발음지도-참고자료-요약.md) — 이번 발음 지도 앱 프로젝트의 교육학적 근거 요약
8. [찬찬한글 참고자료 요약](08-찬찬한글-참고자료-요약.md) — 찬찬한글 교사용·익힘책의 학습 순서와 지도법 요약

10. [음성인식 기술 선택](10-음성인식-기술-선택.md) — Web Speech API 대신 Azure 발음 평가를 선택한 이유와 개인정보 설계 원칙
11. [진행 상황](11-진행상황.md) — 지금까지의 결정, 막힌 지점, 다음에 할 일 (새 채팅에서 이어갈 때 가장 먼저 읽을 문서)

## 이 위키 사용법

- 새로운 내용을 추가할 때는 해당 주제의 파일에 이어서 작성하세요.
- 새 주제가 생기면 번호를 이어서 새 파일을 만들고 이 목차에 링크를 추가하세요.
- 팀 내 실제 사용 사례(프롬프트 예시, 트러블슈팅 기록)는 각 문서 하단에 "사례" 섹션으로 누적하는 것을 권장합니다.
