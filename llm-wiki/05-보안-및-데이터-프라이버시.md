# 보안 및 데이터 프라이버시

## 민감 정보 취급 원칙

- API 키, 고객 개인정보, 사내 기밀 문서 등을 프롬프트에 그대로 넣기 전에 정말 필요한지 검토합니다.
- 로그(요청/응답 저장)에 민감 정보가 남는지 확인하고, 필요하면 마스킹 후 전송합니다.
- 외부에 공개되는 서비스(챗봇 등)에 LLM을 연결할 때는 프롬프트 인젝션 가능성을 염두에 두고, 모델 출력을 그대로 신뢰하지 않습니다 (예: 도구 실행 전 사용자 승인 단계를 두는 등).

## 자격 증명 관리

- API 키를 코드에 하드코딩하지 않고 환경 변수나 시크릿 매니저로 관리합니다.
- `.env` 파일 등은 버전 관리(git)에 커밋하지 않습니다.

## 참고
