# 찬찬한글 참고자료 요약

출처: **&lt;찬찬한글&gt;**(한국교육과정평가원, 2017, 훈민정음 제자원리 + 발음중심 한글 해득 프로그램, 교사용 지도서) + **&lt;찬찬한글 익힘책&gt;**(대전광역시교육청, 찬찬한글을 보충하는 가정학습용 워크북). 세부 문항까지 다 기억할 필요는 없고, **아래 학습 순서와 지도 방법의 큰 흐름**만 발음 지도 앱 설계에 참고한다.

## 전체 학습 순서 (단원 구성)

모음 → 자음 → 받침 없는 단어 읽기 → 복잡한 모음(이중모음) → 복잡한 모음 단어 읽기 → 대표받침(7개) → 대표받침 단어 읽기 → 복잡한 받침(받침가족·겹받침) → 복잡한 받침 단어 읽기 → 최종평가

우리 프로젝트의 "자모 → 음절 → 단어" 순서를 이보다 한 단계 더 세분화한 것이라고 보면 된다.

## 핵심 지도 원리

- **모음을 자음보다 먼저 가르친다.** 모음은 혼자서도 소리를 낼 수 있지만 자음은 모음 없이는 소리를 낼 수 없기 때문이다. 자음 이름(기역, 니은 등)에는 받침소리가 들어 있어, 먼저 배워두면 나중에 받침을 배울 때 유리하다.
- **훈민정음 제자원리로 자모의 모양과 소리를 설명한다.** 모음은 하늘·땅·사람(천지인)과 음양 원리(예: ㅏ·ㅗ는 밝고 나가는 느낌, ㅓ·ㅜ는 어둡고 들어가는 느낌)로, 자음은 조음 위치와 가획 원리(예: ㄱ→ㅋ→ㄲ는 바람 세기가 세짐)로 풀어서 설명한다.
- **발음 중심(상향식) 접근이며, 음소 수준까지 분리해서 지도한다.** 모음 → 자음 → 자모 합성(글자 만들기) → 의미단어 → **무의미 단어**까지 학습한다.
- **직접교수법 사이클**로 각 차시를 구성한다: 이해하기(교사가 모양·소리를 시범) → 따라하기(동작+소리 따라하기) → 쓰기(쓰면서 소리 내어 읽기) → 확인하기(읽기, 듣고 찾기, 글자 만들기 등으로 점검).
- **무의미 단어(뜻이 없는 글자 조합)도 반드시 읽힌다.** 의미 있는 단어만 연습하면 학생이 뜻을 추측해서 "읽는 척"할 수 있기 때문에, 무의미 단어로 진짜 소릿값을 아는지 확인한다.
- **받침은 단계적으로 확장한다**: 먼저 끝소리 규칙에 따른 **대표받침 7개**(ㄱㄴㄷㄹㅁㅂㅇ)를 하나씩 배우고, 이후 같은 소리로 나는 여러 받침을 묶은 **받침가족**(예: ㅂ가족=ㅂ·ㅍ, ㄱ가족=ㄱ·ㅋ·ㄲ, ㄷ가족=ㄷ·ㅅ·ㅆ·ㅈ·ㅊ·ㅌ·ㅎ)과 **겹받침**을 배운다.
- 조음 위치가 비슷한 자음/받침끼리 묶어서 순서를 구성한다(예: ㅁ↔ㅂ, ㅇ↔ㄱ).
- 익힘책(워크북)은 교사 지도 시간 밖에서, 특히 **가정에서의 충분한 반복 연습**을 위해 쓰기 활동을 강화한 보조 교재다.

## 발음 지도 앱 설계에 적용할 점

- 자모 단계에서 모음을 자음보다 먼저 배치한다.
- 음절/단어 문항에 의미단어뿐 아니라 **무의미 단어**도 섞어서, 학생이 뜻을 추측하는 게 아니라 실제로 정확한 소릿값을 내는지 확인하는 문항 유형을 넣는다.
- 받침 단계 난이도를 "대표받침 7개(쉬움) → 받침가족(표기와 발음이 다른 경우, 어려움) → 겹받침(가장 어려움)" 순으로 설계한다.
- 화면/문항 하나의 흐름을 "모범 발음 듣기(이해하기·따라하기) → 학생이 따라 말하기 → 음성인식으로 맞았는지 확인(확인하기)" 구조로 맞추면, 검증된 교수법과 앱의 음성인식 피드백 루프가 자연스럽게 이어진다.
